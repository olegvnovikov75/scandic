# 🌳 Scandic — Скандинавская Мифология

**Интерактивная энциклопедия скандинавской мифологии с полным родословным древом**

---

## 📋 Описание

Scandic — полнофункциональный веб-сайт, посвящённый скандинавской мифологии. Проект включает подробную информацию о божествах, великанах, монстрах и других мифологических существах из древней скандинавской традиции.

### Особенности
- **233 HTML-страницы** — боги, миры, события, руны, семейные страницы
- **67 SVG-иконок + 2 WebP-портрета** — иконки персонажей, оптимизированные изображения, lazy loading
- **Современный дизайн** — тёмная тема "Тёмный Север", адаптивная вёрстка
- **Полные тексты** — Поэтическая и Прозаическая Эдды, Сага о Вельсунгах
- **Интерактивное древo** — визуальное дерево богов
- **9 миров** — полная космология Иггдрасиля
- **CSV-таблица** — все сущности в структурированном виде

```
scandic/
├── index.html              ← Главная страница с древом богов

├── contact.html            ← Контакты
├── gods.html               ← Каталог богов
├── literature.html         ← Источники и эдды

├── family/                 ← 147 семейных страниц персонажей

├── events/                 ← 24 страницы событий/мифов
├── runes/                  ← 35 страниц рун

├── eddas/                  ← Полные тексты Эдд
```

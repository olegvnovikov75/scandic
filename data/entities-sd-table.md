# Scandic — Таблица сущностей для Stable Diffusion

## Инструкция
- **ID** — внутренний номер сущности
- **Сущность** — имя на русском + древнескандинавское
- **Описание** — человеческим языком, что это за персонаж/место/событие
- **Промпт SD** — готовый prompt для Stable Diffusion (вставляй в генератор)
- **Категория** — для понимания стиля промпта
- **Negative prompt:** ugly, blurry, low quality, modern clothing, anime, cartoon, text, watermark

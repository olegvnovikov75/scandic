## 1. Технически
- Статический сайт: HTML5 + CSS3 + чистый JS (без фреймворков, без сборщиков).
- **Без внешних зависимостей:** никаких CDN, внешних шрифтов, внешних картинок. Вся графика — inline SVG или локальные .svg в `img/`. Шрифты — системные стопки (см. дизайн-токены).
- Кодировка UTF-8, `lang="ru"`, семантичный HTML (header/nav/main/section/article/footer).
- Адаптив: десктоп + планшет + телефон (бургер-меню на узких).
- Каталог проекта: `~/Projects/scandic/`. Структура:
  ```
  scandic/
    index.html
    cosmos.html realms.html runes.html creatures.html eddas.html
    ragnarok.html vikings.html timeline.html about.html 404.html
    gods/ (odin thor freya loki tyr heimdall balder njord — .html)
    css/style.css
    js/main.js
    img/ (svg-файлы, если не inline)
  ```
- Публикация: `cd ~/Projects/scandic && setsid nohup python3 -m http.server 9091 > ~/scandic-server.log 2>&1 < /dev/null &`
  Проверка: `curl -s -o /dev/null -w '%{http_code}' http://127.0.0.1:9091/` → 200.

## 2. Дизайн-токены (дизайн-система)
Тема: «ночная Скандинавия» — тёмный, тёплый, с золотом и рунной орнаментикой. Впечатление: монументально, дорого, но читабельно.
```
:root {
  --bg:        #0b0f16;   /* фон: глубокая ночь */
  --bg-2:      #101724;   /* карточки/панели */
  --bg-3:      #16202f;   /* приподнятые элементы */
  --ink:       #e8e0cd;   /* основной текст: тёплый пергамент */
  --ink-dim:   #a89f8a;   /* второстепенный текст */
  --gold:      #c9a227;   /* золото: акценты, линии, hover */
  --gold-soft: #8a6d1d;   /* тёмное золото: рамки */
  --blood:     #8e3b2f;   /* редкий акцент (рагнарёк, лoki) */
  --frost:     #7fb2c9;   /* ледяной акцент (морские боги, нифльхейм) */
  --font-head: Georgia, 'Times New Roman', serif;
  --font-body: 'Segoe UI', system-ui, -apple-system, sans-serif;
  --rune:      'Segoe UI Symbol', 'Noto Sans Runic', sans-serif;
}
```
Обязательные элементы стиля:
- Тонкие золотые линии-разделители (`.ornament`: линия — руна в центре — линия).
- Заголовки страниц: крупный serif, первая буква крупнее (drop cap) где уместно.
- Hover на карточках: подъём + золотая подсветка рамки (плавный transition).
- Герой главной: полноэкранная секция, титр «СКАНДИК», подзаголовок, inline SVG Иггдрасиля справа/сзади (полупрозрачный, тонкие линии), плавное появление (CSS animation, один раз).
- Не перегружать: анимации лёгкие (opacity/translate), без прыжков.
- Читабельность: строка ≤ 75 символов, контраст текста по фону высокий.

## 3. Контракт классов (ВАЖНО — по этим классам Гаечка вёрстает свои страницы)
Общая разметка КАЖДОЙ страницы:
```html
<body>
<header class="nav">
  <a class="nav__logo" href="index.html">ᛋ <span>Скандик</span></a>
  <button class="nav__burger" aria-label="Меню">☰</button>
  <nav class="nav__links"> …ссылки… </nav>
</header>
<main class="main"> …секции… </main>
<footer class="footer"> Скандик · мифология Скандинавии · 2026 </footer>
<script src="js/main.js"></script>
</body>
```
(в gods/ пути с префиксом `../`: `../css/style.css`, `../index.html` и т.д.)
Классы:
- `.nav`, `.nav__logo`, `.nav__burger`, `.nav__links`, `.nav__links a` (активная — `.active`), на мобильных `.nav.open`.
- `.hero` (высота ~92vh, flex по центру), `.hero__rune` (огромная руна/орнамент), `.hero__title`, `.hero__sub`, `.hero__scroll` («вниз»-подсказка).
- `.section` (вертикальные отступы), `.section__title` (h2), `.section__lead` (вводный абзац крупнее).
- `.prose` — контейнер текста: внутри стилизуются `h2/h3/p/ul/ol/blockquote/table` (красивые списки с рунической маркой «·» или «᛫», цитаты с золотой левой гранью).
- `.grid` + `.card` (`.card__title`, `.card__text`, `.card__rune` — угловая руна) — сетка карточек: 1/2/3 колонки (адаптив).
- `.page-head` — «малый герой» внутренних страниц: заголовок, подзаголовок, тонкий орнамент.
- `.ornament` — разделитель (линия—руна—линия).
- `.timeline` / `.timeline__item` / `.timeline__year` / `.timeline__text` — вертикальная лента с золотой осью и точками.
- `.god-hero` — шапка страницы бoga: имя (огромное), эпитеты, `.god-hero__rune` (большая руна), строка «владычество: …».
- `.stat` / `.stat__k` / `.stat__v` — строка-атрибут (Семья / Оружие / Символы / Столица).
- `.table` — стилизованная таблица (руны: знак/имя/значение).
- `.rune-grid`, `.rune-box`, `.rune-box__glyph` (большая руна), `.rune-box__name`, `.rune-box__mean`.
- `.note` — плашка примечания.
- `.btn` — кнопка/ссылка-кнопка (золотая обводка).
